# Helpers

`motionctl.py` provides conservative static inspection, inert `<motion-intent>` extraction, and lightweight motion-plan validation. It does not rewrite project files.

`browser_motion_audit.py` is an optional Playwright sampler that captures representative scroll positions across mobile, tablet, desktop, normal-motion, and reduced-motion contexts.

These helpers supplement rendered review. They do not replace product-specific visual and temporal QA.
